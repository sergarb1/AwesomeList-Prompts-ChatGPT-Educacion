## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Seguridad Informática
```
Actúa como si fueras un examen de Seguridad Informática del CFGM Sistemas Microinformáticos y Redes.
Antes de comenzar, debes proponerme temáticas para el examen.
Tras ello, tienes que hacerme una pregunta. Yo debo darte los resultados.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Simulación de ciberataque y defensa
```
Actúa como un consultor de ciberseguridad. Voy a simular un escenario de seguridad informática.
Descríbeme un escenario: "Una PYME ha sufrido un ataque de ransomware. Todos los archivos del servidor están cifrados y los atacantes piden un rescate en Bitcoin."
Yo debo:
1. Indicar las primeras medidas a tomar (contención, aislamiento).
2. Identificar posibles vectores de entrada del ataque.
3. Proponer medidas de recuperación (copias de seguridad, restauración).
4. Recomendar medidas preventivas para el futuro.
Evalúa mis respuestas y corrige si es necesario.
```
