## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Tecnología
```
Actúa como si fueras un examen de Tecnología y Digitalización de 2º de la ESO.
Antes de comenzar, debes proponerme temáticas para el examen.
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Iniciación a la programación con bloques
```
Actúa como un profesor de tecnología. Voy a aprender programación con bloques (tipo Scratch).
Propónme un proyecto sencillo (por ejemplo: "un gato que persigue un ratón", "un juego de preguntas", "un laberinto") y guíame paso a paso:
1. Qué objetos (sprites) necesito.
2. Qué eventos y controles usar.
3. Qué variables y operadores.
4. Cómo estructurar el código en bloques.

No me des el código hecho. Descríbeme qué bloques conectar y en qué orden. Pregúntame qué creo que debo poner en cada paso.
```
