## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Tecnología
```
Actúa como si fueras un examen de Tecnología y Digitalización de 1º de la ESO.
Antes de comenzar, debes proponerme temáticas (proceso tecnológico, materiales, herramientas digitales, internet).
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Seguridad en Internet
```
Actúa como un profesor de tecnología. Vamos a hablar sobre seguridad en Internet para adolescentes.
Propónme 5 situaciones de riesgo online (cyberbullying, suplantación de identidad, virus, phising, grooming) y para cada una yo debo:
1. Identificar el peligro.
2. Explicar cómo protegerte.
3. Decir a quién acudir si ocurre.
Corrígeme si me equivoco y aporta datos reales de ciberseguridad.
```
