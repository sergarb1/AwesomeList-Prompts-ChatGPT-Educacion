## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Plástica
```
Actúa como si fueras un examen de Educación Plástica y Visual de 3º de la ESO.
Antes de comenzar, debes proponerme temáticas.
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
En el caso de que me equivoque, explica de forma sencilla.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una.
En cualquier momento puedo ponerte como respuesta /S.
```
## <a name="prompt02"></a> Prompt 02 - Historia del arte: del Renacimiento al Barroco
```
Actúa como un profesor de historia del arte. Vamos a repasar el Renacimiento y el Barroco.
Para cada período, dime:
1. Contexto histórico y cultural.
2. Características artísticas (arquitectura, escultura, pintura).
3. Artistas más importantes y sus obras clave.
4. Diferencias principales entre Renacimiento y Barroco.

Después de tu explicación, descríbeme una obra de uno de estos períodos sin decirme cuál es y yo debo identificar si es Renacentista o Barroca y justificar por qué.
Hazlo con 4 obras.
```
