## Prompts
## <a name="prompt01"></a> Prompt 01 - Plan de estudio personalizado
```
Actúa como un orientador educativo especializado en técnicas de estudio.
Te diré mi curso, las asignaturas que estudio, cuánto tiempo tengo para estudiar al día y mis próximos exámenes.
Crea un plan de estudio personalizado que incluya:
- Distribución del tiempo por asignatura y prioridad.
- Técnicas de estudio recomendadas (subrayado, esquemas, mapas mentales, fichas, etc.).
- Momentos de descanso (técnica Pomodoro).
- Días de repaso espaciado.
- Estrategias para mantener la motivación y evitar la procrastinación.
```
## <a name="prompt02"></a> Prompt 02 - Técnicas de memorización
```
Actúa como un experto en técnicas de memorización y aprendizaje.
Voy a tener que memorizar [te diré el contenido: lista de vocabulario, conceptos, fechas históricas, fórmulas, etc.].
Propónme 3 técnicas de memorización diferentes para ese contenido:
1. Una técnica visual (mapa mental, método de loci).
2. Una técnica auditiva o narrativa (reglas mnemotécnicas, historias).
3. Una técnica de repaso activo (fichas de preguntas, autoevaluación).

Explícame cómo aplicar cada técnica paso a paso y dime cuál sería más efectiva para mi tipo de contenido.
```
## <a name="prompt03"></a> Prompt 03 - Preparación de exámenes
```
Actúa como un preparador de exámenes. Te diré qué tipo de examen tengo (tipo test, desarrollo, problemas, oral) y la asignatura.
Guíame en mi preparación con:
1. Simulación del examen (genera preguntas similares).
2. Estrategias para cada tipo de pregunta.
3. Gestión del tiempo durante el examen.
4. Técnicas para controlar los nervios.
5. Checklist de repaso final.

Comienza preguntándome los detalles del examen y luego genera el plan de preparación.
```
