## Prompts
## <a name="prompt01"></a> Prompt 01 — Cuaderno de actividades con evaluación
```
Actúa como un profesor de secundaria especializado en [asignatura].
Crea un cuaderno de actividades para mi clase de [asignatura, curso] sobre el tema [tema concreto].
Debe incluir:
1. 5 actividades de dificultad progresiva (básica, media, avanzada).
2. Cada actividad con su solución explicada paso a paso.
3. Una rúbrica de evaluación para cada actividad con los criterios: contenido, presentación, originalidad.
4. Tiempo estimado para cada actividad.
5. Materiales necesarios.

El lenguaje debe ser claro y adaptado al nivel del alumnado.
```

## <a name="prompt02"></a> Prompt 02 — Corrección de textos con rúbrica
```
Actúa como un profesor de lengua.
Te voy a pasar el texto escrito por un alumno de [curso].
Quiero que lo corrijas indicando:
1. Errores ortográficos (con la palabra correcta).
2. Errores gramaticales y sintácticos.
3. Problemas de coherencia y cohesión.
4. Propuesta de mejora del vocabulario.
5. Una nota numérica del 1 al 10.
6. Un comentario final motivador para el alumno.

Usa un tono constructivo y pedagógico, no solo correctivo.
```

## <a name="prompt03"></a> Prompt 03 — Generar un examen tipo test con soluciones
```
Actúa como un profesor de [asignatura] de [curso].
Crea un examen tipo test de 20 preguntas sobre el tema [tema].
Cada pregunta debe tener 4 opciones (A, B, C, D) y solo una correcta.
Incluye al final la plantilla de soluciones.
Variedad de preguntas:
- 10 de conceptos teóricos.
- 5 de aplicación práctica.
- 5 de análisis o interpretación.
Indica la dificultad de cada pregunta (básica, media, avanzada).
```

## <a name="prompt04"></a> Prompt 04 — Crear una rúbrica de evaluación
```
Actúa como un experto en evaluación educativa.
Crea una rúbrica analítica para evaluar [tipo de trabajo: exposición oral, trabajo escrito, proyecto, etc.] de alumnos de [curso/asignatura].
La rúbrica debe tener:
- 5 criterios de evaluación.
- 4 niveles de logro: Insuficiente (1), Suficiente (2), Notable (3), Sobresaliente (4).
- Descripción clara de cada nivel para cada criterio.
- Ponderación sugerida de cada criterio.
- Espacio para observaciones.

Hazla en formato tabla descriptiva.
```

## <a name="prompt05"></a> Prompt 05 — Plan de tutoría personalizado
```
Actúa como un tutor de secundaria.
Te voy a describir la situación de un alumno (rendimiento académico, comportamiento, situación personal).
Quiero que me propongas un plan de acción tutorial que incluya:
1. Objetivos semanales para las próximas 4 semanas.
2. Técnicas de estudio recomendadas según su perfil.
3. Estrategias de motivación.
4. Pautas para la coordinación con la familia.
5. Indicadores para evaluar el progreso.

Debe ser realista y aplicable en el contexto de un centro público de secundaria.
```

## <a name="prompt06"></a> Prompt 06 — Adaptación curricular para alumnado NEAE
```
Actúa como un profesor especialista en pedagogía terapéutica.
Te voy a describir un alumno con necesidades específicas de apoyo educativo (diagnóstico, curso, asignatura donde necesita apoyo).
Crea una adaptación curricular no significativa que incluya:
1. Objetivos mínimos adaptados (qué debe saber al final).
2. Metodología específica (agrupamientos, tiempos, recursos).
3. Materiales adaptados (tipo de actividades, formato).
4. Evaluación adaptada (criterios, instrumentos, tiempos).
5. Pautas para el profesorado del aula ordinaria.
```

## <a name="prompt07"></a> Prompt 07 — Email a familias sobre incidencia
```
Actúa como un tutor de [curso] de secundaria.
Redacta un email para una familia sobre la siguiente incidencia académica: [describe la situación: faltas de asistencia, bajo rendimiento, problema de conducta, etc.].
El email debe:
1. Ser profesional y empático.
2. Exponer los hechos objetivos.
3. Explicar las consecuencias académicas.
4. Proponer medidas de mejora.
5. Solicitar colaboración familiar.
6. Ofrecer disponibilidad para una reunión.

Debe tener un tono constructivo, no acusatorio.
```

## <a name="prompt08"></a> Prompt 08 — Newsletter del aula semanal
```
Actúa como un tutor de [curso].
Crea una newsletter semanal para informar a las familias sobre la actividad del aula.
Debe incluir:
1. Resumen de lo trabajado esta semana en cada asignatura principal.
2. Fechas de exámenes o entregas importantes próximas.
3. Logros destacados del grupo o de alumnos concretos (sin nombrar).
4. Recomendaciones para repasar en casa.
5. Un consejo educativo breve.
6. Recordatorio de normas o eventos del centro.

Tono cercano pero formal, máximo 300 palabras.
```
