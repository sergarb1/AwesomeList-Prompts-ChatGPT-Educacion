## Prompts
## <a name="prompt01"></a> Prompt 01 — Infografía educativa completa con IA + Canva
```
Actúa como un diseñador gráfico educativo experto en Canva.
Voy a crear una infografía educativa combinando ChatGPT Images (o DALL-E) con Canva Capas Mágicas.
Quiero hacer una infografía sobre [tema educativo] para alumnos de [curso].
Guíame paso a paso:

PASO 1 — Generación de fondos con IA:
Dame un prompt detallado en español (y su versión en inglés) para generar un fondo abstracto o temático relacionado con [tema].
El fondo debe tener espacio libre en el centro para texto y elementos.

PASO 2 — Generación de elementos recortables:
Dame prompts para generar 3-4 elementos visuales relacionados con el tema (iconos, ilustraciones, figuras) con fondo blanco o transparente, para luego recortarlos con Capas Mágicas.

PASO 3 — Composición en Canva:
- Dimensiones: 1080x1920 px (vertical, ideal para compartir).
- Paleta de colores sugerida (4 colores con códigos hex).
- Distribución de los elementos en la infografía.
- Tipografía recomendada (título, subtítulos, cuerpo).
- Efectos de Canva sugeridos (sombras, marcos, degradados).

PASO 4 — Texto incluido:
- Título principal.
- 4 secciones con datos clave (máximo 3 líneas cada una).
- Un call to action o frase final destacada.

Quiero que el resultado sea profesional, visualmente atractivo y pedagógicamente útil.
```

## <a name="prompt02"></a> Prompt 02 — Fondo de diapositiva para presentación
```
Actúa como un creador de presentaciones educativas.
Dame un prompt para generar con IA un fondo de diapositiva para una presentación sobre [tema educativo].
El fondo debe ser:
- Horizontal (1920x1080 px).
- Colores suaves y profesionales (no saturar).
- Con espacio para texto en el centro o en un lateral.
- Textura o patrón sutil relacionado con el tema.
- Sin elementos que distraigan del contenido.

Además, sugiere cómo integrarlo en Canva: ajustes de transparencia, superposición de formas, y paleta de colores complementaria para el texto.
```

## <a name="prompt03"></a> Prompt 03 — Elementos recortables con Capas Mágicas
```
Actúa como un experto en Canva Capas Mágicas.
Necesito generar elementos visuales para mis materiales educativos que luego pueda separar del fondo con Capas Mágicas.
Dame prompts de IA para generar:

1. Un conjunto de [iconos educativos sobre tema: ciencia, historia, etc.] en estilo plano, fondo blanco, colores vivos.
2. [3-5 personajes o figuras] relacionadas con [tema] con fondo blanco o transparente.
3. [Elementos decorativos: nubes, estrellas, flechas, formas geométricas] en estilo coherente.

Para cada prompt, explica cómo usar Capas Mágicas para separar el elemento del fondo y cómo integrarlo en una infografía o presentación de Canva.
```

## <a name="prompt04"></a> Prompt 04 — Póster científico para el aula
```
Actúa como un diseñador de pósters educativos.
Voy a crear un póster científico sobre [tema: el ciclo del agua, las capas de la atmósfera, la tabla periódica, etc.] para decorar el aula de [asignatura].
El póster debe medir 50x70 cm (vertical).
Dame:
1. Un prompt para generar el fondo visual principal con IA (relacionado con el tema, con espacio para superposición de texto).
2. La estructura del póster: título grande en la parte superior, secciones con información clave, diagrama central, curiosidades en la parte inferior.
3. Paleta de colores sugerida (5 colores máx.) con códigos hex.
4. Tipografía para títulos y cuerpo.
5. Sugerencias de elementos decorativos recortables con Capas Mágicas.
```

## <a name="prompt05"></a> Prompt 05 — Línea de tiempo visual
```
Actúa como un diseñador de líneas de tiempo educativas.
Necesito crear una línea de tiempo visual sobre [período histórico, biografía, evolución de un concepto] para alumnos de [curso].
Diseña la línea de tiempo con:
1. Un prompt para generar un fondo degradado o texturizado con IA.
2. La estructura visual: línea central con 6-8 hitos, alternando arriba/abajo.
3. Iconos o imágenes sugeridos para cada hito (generables con IA).
4. Colores por período o categoría.
5. Fechas destacadas con tamaño de fuente mayor.
6. Breve descripción de cada hito (máximo 15 palabras por hito).

Indica cómo montarlo en Canva: usar Capas Mágicas para los iconos, formas para los recuadros de texto, y líneas con la herramienta de dibujo.
```

## <a name="prompt06"></a> Prompt 06 — Cartel de normas del aula
```
Actúa como un diseñador de cartelería educativa.
Crea un cartel visual de normas del aula para [curso/nivel] usando IA + Canva.
El cartel debe:
1. Tener un fondo generado por IA (colores suaves, estilo acogedor).
2. Incluir 5-6 normas escritas de forma positiva ("Sí podemos..." en lugar de "No...").
3. Cada norma debe ir acompañada de un icono o pictograma generado con IA.
4. Tipografía grande y legible desde lejos.
5. Esquema de colores: 3 colores máximo (uno de fondo, uno para texto, uno para acentos).
6. Tamaño: A3 vertical.

Proporciona los prompts de IA para cada elemento y las instrucciones de montaje en Canva (Capas Mágicas, marcos, textos).
```

## <a name="prompt07"></a> Prompt 07 — Mapa mental interactivo
```
Actúa como un facilitador visual para el aprendizaje.
Diseña un mapa mental sobre [tema: teorías del aprendizaje, ecosistemas, géneros literarios, etc.].
El mapa debe tener:
1. Concepto central con una imagen generada por IA (prompt incluido).
2. 5-7 ramas principales, cada una con un color distinto.
3. Palabras clave en cada rama (máximo 3 palabras).
4. Iconos o mini ilustraciones en las ramas secundarias (generadas con IA y recortables con Capas Mágicas).
5. Flechas o conectores entre conceptos relacionados.
6. Formato: horizontal, apto para imprimir en A3.

Da instrucciones precisas para montarlo en Canva, incluyendo atajos y herramientas específicas.
```

## <a name="prompt08"></a> Prompt 08 — Portada de cuaderno o dossier
```
Actúa como un creador de portadas educativas personalizadas.
Diseña una portada para un cuaderno o dossier de [asignatura/curso] usando IA + Canva Capas Mágicas.
La portada debe tener:
1. Prompt para generar un fondo abstracto o temático con IA (colores representativos de la asignatura).
2. Título de la asignatura en fuente decorativa pero legible.
3. Curso escolar y nombre del alumno (espacio reservado).
4. 2-3 elementos decorativos recortables relacionados con la asignatura.
5. Un marco o borde decorativo.
6. Dimensiones: 21x29.7 cm (A4).

Proporciona los prompts de IA para cada elemento visual y el paso a paso de montaje en Canva.
```
