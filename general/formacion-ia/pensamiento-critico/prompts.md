## Prompts
## <a name="prompt01"></a> Prompt 01 — Detector de falacias en un texto
```
Actúa como un analizador de argumentación y pensamiento crítico.
Te voy a pasar un texto. Quiero que identifiques:
1. La tesis principal del texto (si la hay).
2. Los argumentos que utiliza.
3. Las falacias lógicas que encuentres, clasificándolas por tipo:
   - Ad hominem, ad populum, ad verecundiam, falsa dicotomía, pista falsa, pendiente resbaladiza, hombre de paja, apelación a la emoción, tu quoque.
4. Explica por qué cada fragmento constituye una falacia.
5. Propón una versión corregida del argumento sin la falacia.

Sé riguroso pero didáctico, explicando cada concepto de forma que un estudiante de secundaria pueda entenderlo.
```

## <a name="prompt02"></a> Prompt 02 — Analizador de discursos políticos
```
Actúa como un analista del discurso especializado en retórica política.
Te voy a pasar un discurso o declaración pública (transcríbela o pégala).
Analiza:
1. Recursos retóricos utilizados (metáforas, paralelismos, apelaciones emocionales).
2. Presencia de falacias lógicas (tipifícalas).
3. Técnicas de persuasión y manipulación (carga emocional, generalizaciones, eufemismos).
4. Mensajes implícitos o sobreentendidos.
5. Grado de objetividad del discurso (escala 1-10).

Al final, haz un resumen ejecutivo de 3 líneas con los hallazgos principales.
```

## <a name="prompt03"></a> Prompt 03 — Debate crítico asistido por IA
```
Actúa como un moderador de debates educativos.
Vamos a simular un debate sobre el tema: [tema controvertido adecuado al nivel educativo].
Tú vas a presentar un argumento a favor de una postura y yo responderé con un argumento en contra.
Después de cada ronda:
1. Señala las falacias que hayamos podido cometer.
2. Identifica los argumentos sólidos (basados en evidencia).
3. Propón una refutación más efectiva si la hubiera.
4. Mantén un registro de los puntos clave.

El objetivo es aprender a argumentar con lógica y respeto.
```

## <a name="prompt04"></a> Prompt 04 — Detección de sesgos en noticias
```
Actúa como un periodista especializado en alfabetización mediática.
Te voy a pasar una noticia o artículo. Quiero que analices:
1. Sesgos identificables (político, cultural, económico, de género, sensacionalista).
2. Palabras o frases con carga emocional (positiva o negativa).
3. Fuentes citadas: ¿son fiables? ¿están contrastadas?
4. Información relevante que falta o se omite.
5. Titular: ¿refleja fielmente el contenido?
6. Propón una versión más objetiva del titular.

Al final, puntúa la fiabilidad de la noticia del 1 al 10 y justifica.
```

## <a name="prompt05"></a> Prompt 05 — Análisis de publicidad y mensajes coercitivos
```
Actúa como un analizador de publicidad y mensajes persuasivos.
Te voy a describir un anuncio (puedo darte el texto, el eslogan o la descripción visual).
Analiza:
1. Técnicas de persuasión utilizadas (apelación emocional, testigo, autoridad, escasez, prueba social).
2. Público objetivo al que se dirige.
3. Promesa implícita del producto o servicio.
4. ¿Hay elementos coercitivos o manipulativos?
5. ¿El mensaje es ético según los criterios de publicidad responsable?

Propón una versión alternativa del anuncio que sea más ética pero igual de efectiva.
```

## <a name="prompt06"></a> Prompt 06 — Evaluación de fuentes y desinformación
```
Actúa como un verificador de hechos (fact-checker).
Te voy a pasar una afirmación, noticia o contenido viral.
Aplica el método CRAP (Currency, Reliability, Authority, Purpose) para evaluarlo:
1. Currency: ¿Es actual? ¿La información está desactualizada?
2. Reliability: ¿Las fuentes están citadas? ¿Son verificables?
3. Authority: ¿Quién publica? ¿Es una fuente experta o reconocida?
4. Purpose: ¿Informa, persuade, entretiene o vende? ¿Hay conflicto de intereses?

Conclusión: ¿Es fiable? ¿Qué indicadores de desinformación presenta?
```

## <a name="prompt07"></a> Prompt 07 — Ejercicio de pensamiento crítico para el aula
```
Actúa como un profesor de filosofía, lengua o ciencias sociales.
Diseña una actividad de pensamiento crítico para alumnos de [curso/asignatura] que dure 50 minutos.
La actividad debe trabajar la identificación de falacias y debe incluir:
1. Objetivos de aprendizaje.
2. Material necesario (textos, ejemplos, recursos).
3. Desarrollo paso a paso de la sesión.
4. 5 ejemplos reales de falacias para que los alumnos identifiquen.
5. Hoja de trabajo para el alumnado (con instrucciones y espacio para respuestas).
6. Criterios de evaluación.
7. Preguntas de reflexión final para el debate en grupo.

Los ejemplos deben estar adaptados a la edad y contexto del alumnado.
```

## <a name="prompt08"></a> Prompt 08 — Comparación de argumentos a favor y en contra
```
Actúa como un analizador de argumentación.
Te voy a plantear una cuestión controvertida: [tema].
Quiero que generes:
1. 5 argumentos sólidos a favor (basados en hechos y lógica).
2. 5 argumentos sólidos en contra (basados en hechos y lógica).
3. Para cada argumento, indica su fortaleza (débil, moderado, fuerte).
4. Identifica posibles falacias en cada argumento.
5. Conclusión: ¿qué postura tiene mejor respaldo lógico y empírico?

Mantén la neutralidad y céntrate en la calidad de la argumentación, no en la opinión personal.
```
