## Prompts
## <a name="prompt01"></a> Prompt 01 — Ilustración científica para un tema
```
Actúa como un ilustrador científico especializado en educación.
Genera una descripción detallada para crear una imagen educativa sobre [tema científico: ciclo del agua, partes de una célula, sistema solar, etc.].
La imagen debe ser:
- Didáctica y clara, apta para alumnos de [curso].
- Con etiquetas o rótulos para las partes principales.
- Con colores que faciliten la diferenciación de elementos.
- Estilo: infografía educativa, fondo blanco, líneas limpias.

Describe la imagen con suficiente detalle para que un generador de imágenes (DALL-E, Midjourney, etc.) pueda crearla.
Incluye sugerencias de prompt en inglés para el generador de imágenes.
```

## <a name="prompt02"></a> Prompt 02 — Mapa conceptual visual
```
Actúa como un diseñador instruccional.
Crea un mapa conceptual visual sobre [tema de cualquier asignatura].
El mapa debe organizar los conceptos principales y sus relaciones.
Describe visualmente:
1. Concepto principal en el centro (tamaño grande, color destacado).
2. Conceptos secundarios alrededor (tamaño medio, colores distintos).
3. Conexiones y palabras de enlace entre conceptos.
4. Ejemplos concretos en los extremos.
5. Iconos o símbolos sugeridos para cada concepto.

Propón el prompt en español para generarlo con ChatGPT Images o herramientas similares.
```

## <a name="prompt03"></a> Prompt 03 — Worksheet ilustrada para primaria
```
Actúa como un creador de materiales educativos para educación primaria.
Diseña una ficha de trabajo (worksheet) ilustrada sobre [tema: los animales, el cuerpo humano, las plantas, etc.] para alumnos de [curso].
La ficha debe incluir:
1. Un título llamativo y colorido.
2. 3-4 actividades visuales (unir con flechas, colorear, rodear, completar).
3. Ilustraciones en cada actividad (describe qué debe aparecer).
4. Instrucciones claras y sencillas en cada actividad.
5. Un espacio para el nombre del alumno.
6. Un pequeño reto o juego al final.

Describe cada elemento visual con precisión para poder generarlo con IA.
```

## <a name="prompt04"></a> Prompt 04 — Infografía explicativa
```
Actúa como un diseñador gráfico educativo.
Crea la descripción de una infografía sobre [tema: cambio climático, revolución industrial, funciones matemáticas, etc.] para nivel de [curso].
La infografía debe tener:
1. Un título principal impactante.
2. 4-5 secciones con datos clave, cada una con un icono distintivo.
3. Una línea de tiempo, gráfico o diagrama central.
4. Colores coordinados (máximo 4 colores).
5. Fuente legible y jerarquía visual clara.
6. Un dato sorprendente o curiosidad destacada.
7. Logos o marcas de agua si procede.

Proporciona el prompt detallado en español para generarla con IA.
```

## <a name="prompt05"></a> Prompt 05 — Secuencia de viñetas para un proceso
```
Actúa como un creador de cómics educativos.
Diseña una secuencia de viñetas que explique paso a paso [un proceso: cómo se forma un fósil, cómo funciona el sistema digestivo, cómo resolver una ecuación, etc.].
Cada viñeta debe incluir:
1. Un título breve (ej: "Paso 1: Ingestión").
2. Una descripción visual de lo que ocurre.
3. Un texto explicativo corto (máximo 2 líneas).
4. Personajes o elementos visuales que guíen al espectador.

La secuencia debe tener entre 4 y 6 viñetas y ser comprensible para alumnos de [curso].
```

## <a name="prompt06"></a> Prompt 06 — Tarjetas educativas (flashcards visuales)
```
Actúa como un creador de tarjetas educativas visuales.
Diseña un conjunto de 10 tarjetas (flashcards) sobre [tema: vocabulario de inglés, capitales del mundo, elementos químicos, etc.] para [curso].
Cada tarjeta debe tener:
- Anverso: imagen o icono representativo + palabra o concepto.
- Reverso: definición breve, traducción o explicación.
- Diseño limpio, colores por categoría.
- Tamaño adecuado para imprimir y recortar.

Describe el diseño visual de cada tarjeta y propón el prompt para generarlas con IA.
```

## <a name="prompt07"></a> Prompt 07 — Retrato histórico o literario
```
Actúa como un ilustrador de material didáctico de historia y literatura.
Genera una descripción detallada para crear el retrato visual de [personaje histórico o literario: Cervantes, Marie Curie, Don Quijote, etc.].
La imagen debe ser:
- Estilo realista o semirrealista, apto para libro de texto.
- Vestimenta y ambiente de la época correspondiente.
- Elementos característicos que identifiquen al personaje (objetos, vestimenta, entorno).
- Fondo neutro o contextual (según el uso).
- Colores apropiados a la época.

Incluye referencias históricas precisas en la descripción.
```

## <a name="prompt08"></a> Prompt 08 — Escena histórica o literaria
```
Actúa como un ilustrador de escenas educativas.
Crea la descripción visual de una escena clave de [evento histórico u obra literaria: la firma de la Constitución de 1812, el momento en que don Quijote lucha contra los molinos, etc.].
La escena debe incluir:
1. Ambientación detallada (lugar, época, iluminación).
2. Personajes principales con sus rasgos distintivos.
3. Acción o momento congelado que represente el evento.
4. Elementos simbólicos o contextuales relevantes.
5. Composición que guíe la mirada hacia el elemento central.

Proporciona el prompt en español y una versión en inglés para generadores de imágenes.
```
