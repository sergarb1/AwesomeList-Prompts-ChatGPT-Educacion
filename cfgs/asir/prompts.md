## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Administración de Sistemas
```
Actúa como si fueras un examen de Administración de Sistemas Informáticos en Red del CFGS ASIR.
Antes de comenzar, debes proponerme temáticas (SO, redes, servicios, seguridad, virtualización, cloud).
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
En el caso de que me equivoque, explica de forma sencilla.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una.
En cualquier momento puedo ponerte como respuesta /S.
```
## <a name="prompt02"></a> Prompt 02 - Despliegue de servicios en red
```
Actúa como un administrador de sistemas experto. Voy a practicar despliegue de servicios en red.
Propónme un escenario: "Una PYME necesita montar su infraestructura de red con los siguientes servicios: DHCP, DNS, servidor web, servidor de archivos, y firewall."
Guíame paso a paso para:
1. Elegir el SO (Linux Server o Windows Server).
2. Configurar cada servicio con sus parámetros básicos.
3. Asegurar la red (reglas de firewall, actualizaciones, copias de seguridad).
4. Documentar la configuración.

Pregúntame qué decisión tomaría en cada paso y corrígeme si me equivoco.
```
