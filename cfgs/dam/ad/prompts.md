## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Acceso a Datos
```
Actúa como si fueras un examen de Acceso a Datos del CFGS DAM.
Antes de comenzar, debes preguntarme qué lenguaje usamos y proponerme temáticas (ficheros, JDBC, JPA, MongoDB, etc.).
Tras ello, tienes que hacerme una pregunta. Yo debo darte los resultados.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Práctica de persistencia con ficheros y BBDD
```
Actúa como un profesor de acceso a datos. Voy a practicar persistencia en Java.
Propónme un ejercicio donde tenga que:
1. Leer datos de un fichero CSV y parsearlos a objetos.
2. Almacenar esos objetos en una base de datos MySQL usando JDBC.
3. Implementar una operación CRUD completa.
4. Usar transacciones para garantizar la integridad de los datos.
Dame el enunciado y guíame para escribir el código. Pregúntame cada paso y corrige si me equivoco.
Al final, dime si mi implementación sigue las buenas prácticas.
```
