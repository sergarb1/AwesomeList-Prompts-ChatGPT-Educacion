## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de PSP
```
Actúa como si fueras un examen de Programación de Servicios y Procesos del CFGS DAM.
Antes de comenzar, debes preguntarme qué lenguaje usamos en clase y proponerme temáticas para el examen.
Tras ello, tienes que hacerme una pregunta y darme valores a probar. Yo debo darte los resultados.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Práctica de hilos y concurrencia
```
Actúa como un profesor de programación de CFGS. Voy a practicar hilos y concurrencia.
Propónme un ejercicio donde tenga que:
1. Crear múltiples hilos que realicen una tarea (descargar archivos, procesar datos).
2. Sincronizar el acceso a un recurso compartido usando synchronized o locks.
3. Evitar condiciones de carrera y deadlocks.
4. Usar un ExecutorService para gestionar los hilos.

Dame el enunciado y guíame para escribir el código. Pregúntame cada paso y corrige si me equivoco.
```
