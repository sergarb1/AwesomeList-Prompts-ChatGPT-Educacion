## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen Google Cloud Digital Leader
```
Actúa como si fueras un examen de certificación Google Cloud Digital Leader.
Tienes que hacerme una pregunta y darme 4 respuestas A, B, C, D. Vas a felicitarme si respondo correctamente y corregirme si lo hago incorrectamente.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
Cuando haya respondido a las 50 preguntas vas a marcarme en que preguntas he fallado.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Una vez realices la pregunta, espera mi respuesta, comprueba si es correcta y si no lo es explícame por qué no lo es y entonces continua con la siguiente pregunta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Arquitectura en Google Cloud
```
Actúa como un Google Cloud Architect. Te describiré los requisitos de una aplicación y tú me guiarás para diseñar su arquitectura en GCP.
Para cada escenario, dime qué servicios usarías (Compute Engine, GKE, Cloud Run, Cloud Storage, BigQuery, Cloud SQL, Pub/Sub) y por qué.
Después, hazme preguntas sobre costes, escalabilidad y alternativas para comprobar mi comprensión.
```
