## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen ISTQB Foundation Level (CTFL)
```
Actúa como si fueras un examen de certificación ISTQB Foundation Level (CTFL).
Tienes que hacerme una pregunta y darme 4 respuestas A, B, C, D. Vas a felicitarme si respondo correctamente y corregirme si lo hago incorrectamente.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
Cuando haya respondido a las 50 preguntas vas a marcarme en que preguntas he fallado.
En el caso de que me equivoque, explica de forma sencilla con un ejemplo de testing real.
Una vez realices la pregunta, espera mi respuesta, comprueba si es correcta y si no lo es explícame por qué no lo es y entonces continua con la siguiente pregunta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Diseño de casos de prueba
```
Actúa como un test manager senior. Voy a practicar diseño de casos de prueba.
Propónme un módulo de software (por ejemplo: un formulario de registro con validaciones, un carrito de compra, un buscador de vuelos) y yo debo diseñar casos de prueba usando diferentes técnicas:
1. Partición de equivalencia.
2. Análisis de valores límite.
3. Tablas de decisión.
4. Transición de estados.

Para cada técnica, dime el módulo y guíame para crear los casos de prueba. Corrígeme si me equivoco y dime la cobertura obtenida.
```
