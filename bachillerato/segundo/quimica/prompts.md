## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Química
```
Actúa como si fueras un examen de Química de 2º de Bachillerato en el sistema educativo español.
Antes de comenzar, debes proponerme temáticas para el examen. Cuando yo elija la tematica, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte esa pregunta. Si hay cálculos, me darás los valores.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Problemas de equilibrio químico
```
Actúa como un profesor de química de 2º de bachillerato. Voy a practicar problemas de equilibrio químico.
Propónme un problema donde tenga que:
1. Escribir la expresión de la constante de equilibrio Kc.
2. Calcular las concentraciones en el equilibrio a partir de datos iniciales y de Kc.
3. Aplicar el principio de Le Châtelier para predecir el desplazamiento del equilibrio.
Guíame paso a paso, pidiéndome cada cálculo por separado. Corrígeme si me equivoco.
Al final, verifica si mis resultados son correctos.
```
