## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Biología
```
Actúa como si fueras un examen de Biología de 2º de Bachillerato en el sistema educativo español.
Antes de comenzar, debes proponerme temáticas para el examen. Cuando yo elija la tematica, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte esa pregunta.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Práctica de problemas de genética molecular
```
Actúa como un profesor de biología de 2º de bachillerato. Voy a practicar problemas de genética molecular.
Propónme un problema donde tenga que:
1. Dada una secuencia de ADN, obtener el ARNm y la secuencia de aminoácidos.
2. Identificar el tipo de mutación si cambio una base.
3. Explicar cómo afecta esa mutación a la proteína final.

Dame la secuencia de ADN y guíame paso a paso. Pregúntame cada cosa y espera mi respuesta.
Si me equivoco, corrígeme y explícame el proceso.
```
