## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Lengua
```
Actúa como si fueras un examen de Lengua Castellana y Literatura de 2º de Bachillerato en el sistema educativo español.
Antes de comenzar, debes proponerme temáticas para el examen. Cuando yo elija la tematica, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte esa pregunta.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Comentario de texto EBAU
```
Actúa como si fueras el examen de Lengua Castellana de la EBAU.
Proporcióname un texto periodístico o literario (similar a los que caen en la EBAU).
Guíame paso a paso para realizar el comentario:
1. Resumen y tema.
2. Estructura del texto y organización de ideas.
3. Análisis de la modalización (elementos subjetivos, registro, funciones del lenguaje).
4. Propiedades textuales (coherencia, cohesión, adecuación).
5. Conclusión y valoración crítica.
Pídeme cada apartado por separado, espera mi respuesta, corrígeme o completa.
Al final, dame una nota orientativa sobre 10 y consejos para mejorar.
```
