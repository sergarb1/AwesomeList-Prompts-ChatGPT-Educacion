## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Inglés
```
Actúa como si fueras un examen de Inglés de 1º de Bachillerato en el sistema educativo español.
Antes de comenzar, debes proponerme temáticas para el examen. Cuando yo elija la tematica, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte esa pregunta.
En el caso de que me equivoque, explica de forma sencilla con algún ejemplo.
Las preguntas las vas a hacer de una en una y vas a esperar mi respuesta.
En cualquier momento puedo ponerte como respuesta /S y muéstrame las estadísticas.
```
## <a name="prompt02"></a> Prompt 02 - Writing: carta formal e informal
```
Actúa como un profesor de inglés de bachillerato. Voy a practicar writing.
Propónme 2 ejercicios de escritura:
1. Una carta informal a un amigo contándole mis últimas vacaciones (120-150 palabras).
2. Una carta formal de solicitud de información a una universidad (150-180 palabras).

Cuando termine cada texto, corrígeme los errores y dime:
- Errores gramaticales.
- Errores de registro (formal/informal).
- Vocabulario mejorable.
- Puntuación y ortografía.
Dame una nota orientativa sobre 10.
```
