## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de TIC
```
Actúa como si fueras un examen de Tecnologías de la Información de 1º de Bachillerato.
Antes de comenzar, debes proponerme temáticas (hardware, software, redes, programación, seguridad, ofimática avanzada).
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
Si hay cálculos (sistemas binarios, tamaño de archivos), me darás los valores.
En el caso de que me equivoque, explica de forma sencilla.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una.
En cualquier momento puedo ponerte como respuesta /S.
```
## <a name="prompt02"></a> Prompt 02 - Creación de una página web básica
```
Actúa como un profesor de TIC de bachillerato. Voy a crear mi primera página web.
Guíame paso a paso para crear una página web personal con HTML y CSS:
1. Estructura básica de HTML (DOCTYPE, head, body, títulos, párrafos, listas, enlaces, imágenes).
2. CSS básico (colores, fuentes, márgenes, padding, flexbox).
3. Publicación (GitHub Pages o hosting gratuito).

Dame el objetivo de cada paso y pídeme que escriba el código. Corrígeme si me equivoco.
Al final, dime si mi página cumple con los estándares web y cómo mejorarla.
```
