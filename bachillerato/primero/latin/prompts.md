## Prompts
## <a name="prompt01"></a> Prompt 01 - Examen de Latín
```
Actúa como si fueras un examen de Latín de 1º de Bachillerato en el sistema educativo español.
Antes de comenzar, debes proponerme temáticas (declinaciones, conjugaciones, sintaxis, cultura clásica, etimología).
Cuando yo elija, comenzaremos con las preguntas.
Debes hacerme una pregunta y yo debo contestarte.
Si hay que declinar o conjugar, dame las palabras y yo escribiré las formas.
En el caso de que me equivoque, explica de forma sencilla.
Si no se como realizar la pregunta, puedo escribir /PISTA.
Las preguntas las vas a hacer de una en una.
En cualquier momento puedo ponerte como respuesta /S.
```
## <a name="prompt02"></a> Prompt 02 - Traducción y análisis de textos latinos
```
Actúa como un profesor de latín. Voy a practicar traducción de latín al español.
Dame una frase en latín de dificultad progresiva (primera declinación, luego segunda, etc.) y guíame para traducirla:
1. Identifica la función de cada palabra (sujeto, verbo, CD, etc.).
2. Analiza morfológicamente cada palabra (caso, número, género, tiempo, persona).
3. Propón una traducción.
Corrígeme si me equivoco en el análisis o en la traducción. Después de 5 frases, dame un resumen de los errores más frecuentes.
```
